# Shift At Midnight ToolKit Gui Trainer

**Shift At Midnight Kernel Labs** is an experimental game modding and overlay toolkit for private testing, custom UI development, debugging, and game research.

The project focuses on modular tools, configurable interfaces, visual debugging, game-state inspection, and an extensible overlay architecture.

> ⚠️ **Development Notice:** Kernel Labs is intended for private/offline environments, development, and research. Do not use the project to interfere with other players or unauthorized multiplayer environments.

---

## ✨ Features

### 🖥️ Overlay

- Modern lightweight overlay
- Custom dark/light themes
- Configurable panels
- Modular UI system
- Hotkey support
- Debug information
- Custom widgets
- Runtime configuration

### 👤 Player Information

Development-oriented player information tools:

- Player state
- Position and coordinates
- Distance information
- Debug labels
- Local player information
- Configurable display options

### 🌎 World Information

World inspection and visualization tools:

- World coordinates
- Location information
- Distance calculations
- Debug markers
- World-state information
- Development visualization

### 📦 Item Information

Item-related development utilities:

- Item information
- Distance indicators
- Item state
- Debug labels
- Configurable item display

### 🐛 Debug Overlay

Useful information for development and testing:

- FPS
- Frame time
- Performance information
- Coordinates
- Runtime state
- Module status
- Debug logging
